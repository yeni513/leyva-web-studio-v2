# Meta Ads Starter — Version Dios

Help set up a safe Facebook/Instagram Ads service for a local business.

## Important rule

Management fee is separate from ad spend. The client pays Meta separately.

## Best uses

Restaurants, events, offers, local services, visual businesses, stores, promotions, brand awareness, messages.

## Setup steps

1. Confirm objective: messages, leads, calls, traffic, engagement.
2. Confirm local radius.
3. Prepare images/videos.
4. Create 2–3 ad angles.
5. Create copy variations.
6. Set starter budget.
7. Launch campaign.
8. Check weekly.
9. Pause losers and improve winners.
10. Send monthly report.

## Output

Create campaign plan, ad angles, copy, creative checklist, budget recommendation, and report template.
