# Start Project — Version Dios

Start a new Leyva Web Studio project with elite structure and no missing details.

## First inspect

Before coding, inspect:

- Package manager
- Framework
- App/router structure
- Existing pages/routes
- Styling system
- shadcn/ui status
- Components
- Public assets
- Environment variables
- Deployment target

## Discovery assumptions

If client data is missing, create a clear assumption list instead of blocking unnecessarily.

Need to define:

- Business name
- Industry
- City/service area
- Target customer
- Main offer
- Main CTA
- Phone/WhatsApp
- Address/hours
- Services/products
- Brand style
- Photos/videos/logo
- Competitors/inspiration
- Monthly service upsell

## Output

Create:

1. Project summary
2. Sitemap
3. Homepage section order
4. Component plan
5. Data file plan
6. SEO plan
7. Conversion plan
8. Mobile plan
9. Build sequence
10. Risks/missing info

Then begin implementation only when the plan is clear.
