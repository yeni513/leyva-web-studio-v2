# Conversion Audit — Version Dios

Audit for leads, calls, WhatsApp messages, appointments, orders, and quotes.

## Check

- Clear offer in 5 seconds
- CTA above fold
- Mobile CTA
- Trust before ask
- Phone/WhatsApp visibility
- Forms length
- Objections answered
- CTA specificity
- Section flow
- Final CTA

## Output

1. Conversion score
2. Biggest leaks
3. CTA fixes
4. Copy fixes
5. Layout fixes
6. Trust fixes
7. Exact code changes

Then implement high-impact fixes if safe.
