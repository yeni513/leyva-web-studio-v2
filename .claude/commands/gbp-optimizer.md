# Google Business Profile Optimizer — Version Dios

Optimize a Google Business Profile plan for a local business.

## Check

- Business name consistency
- Category
- Services/products
- Description
- Hours
- Phone
- Website link
- Address/service area
- Photos
- Reviews strategy
- Posts
- Q&A

## Output

Create optimization checklist, suggested description, services list, review request message, monthly posting plan, and reporting checklist.
