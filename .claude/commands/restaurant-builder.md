# Restaurant Builder — Version Dios

Build or upgrade a premium restaurant website.

## Goals

Make visitors hungry, build trust, show menu, reveal hours/location, and drive calls, directions, orders, WhatsApp, or catering leads.

## Sections

- Hero with food visual
- Menu preview
- Featured dishes
- Gallery
- Story/atmosphere
- Catering/events
- Reviews
- Hours/location
- Delivery/order options
- FAQ
- Final CTA

## CTAs

View Menu, Call Now, Get Directions, Order Online, Book Catering, Message on WhatsApp.

## SEO

Cuisine + city + signature dishes + catering + family-friendly when relevant.

## Output

Implement polished restaurant components, reusable menu data, mobile CTA, and local SEO.
