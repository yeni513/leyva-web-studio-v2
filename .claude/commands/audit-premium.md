# Audit Premium — Version Dios

Audit the website like an elite agency creative director, frontend architect, conversion strategist, and local SEO expert.

## Score 1–10

Score:

- First impression
- Premium feel
- Mobile UX
- Hero clarity
- CTA strength
- Visual hierarchy
- Spacing
- Typography
- Trust/proof
- Local SEO
- Conversion path
- Accessibility
- Performance
- Code organization

## Identify

- What looks generic
- What looks cheap
- What feels unfinished
- What hurts trust
- What hurts leads
- What is weak on mobile
- What is missing for SEO
- What is technically risky

## Output

1. Executive summary
2. Top 10 priority fixes
3. Section-by-section notes
4. Mobile-specific fixes
5. SEO fixes
6. Conversion fixes
7. Code/component fixes
8. Exact implementation plan

Be brutally honest and then fix what is safe to fix.
