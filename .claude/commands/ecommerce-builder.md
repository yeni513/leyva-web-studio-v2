# E-commerce / Catalog Builder — Version Dios

Plan or build product catalog, online store, inventory, or quote system.

## First classify

1. Simple catalog + WhatsApp CTA
2. Catalog with filters/search
3. Full cart + Stripe checkout
4. Admin/inventory dashboard
5. Quote-based product system

## Do not overbuild

Recommend the simplest profitable version first.

## Features

Catalog:
- Product grid
- Categories
- Search/filter
- Product details
- WhatsApp inquiry

E-commerce:
- Cart
- Checkout
- Stripe
- Order confirmation

Inventory/admin:
- Supabase
- Auth
- Product CRUD
- Stock status
- Image management

## Output

Recommend level, explain why, then implement the safest phase.
