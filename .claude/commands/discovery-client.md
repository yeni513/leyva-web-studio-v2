# Discovery Client — Version Dios

Create a complete client intake system for a website project.

## Generate

1. Full professional questionnaire
2. Short WhatsApp questionnaire
3. Email questionnaire
4. Asset checklist
5. Access checklist
6. SEO keyword discovery
7. Competitor discovery
8. Pricing/scope confirmation
9. Monthly services interest section
10. Red flags list

## Must collect

- Business name
- Legal/name display preference
- Industry
- City/service area
- Phone/WhatsApp
- Email
- Address/hours
- Logo
- Photos/videos
- Services/products
- Prices if public
- Offers/promotions
- Reviews/testimonials
- Social links
- Domain access
- Hosting access
- Google Business Profile access
- Inspiration websites
- Competitors
- Main goal
- Deadline
- Budget

## Output

Create the questionnaire plus a clean `/docs/client-brief.md` template.
