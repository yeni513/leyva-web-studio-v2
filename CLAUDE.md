# Project: Leyva Web Studio — Final Boss Portfolio

You are helping build a premium personal web developer website for selling web design and development services to local businesses.

## Main Goal

Create a high-end, modern, uncommon, conversion-focused website that makes the owner look like a serious web professional and helps convert visitors into paying clients.

This site must not feel generic, basic, flat, or template-like. It should feel premium, sharp, trustworthy, and memorable.

## Tech Stack

Use:

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion or Motion
- Lucide React icons
- Optional Magic UI-inspired components
- Optional Aceternity-inspired visual patterns
- shadcn Blocks inspiration
- Godly.website inspiration

## Design Direction

Style:

- Premium dark mode
- Modern gradients
- Clean spacing
- Strong contrast
- Smooth hover states
- Microanimations
- Professional shadows
- Beautiful rounded cards
- Clear CTA buttons
- Mobile-first responsive layout

Avoid:

- Generic buttons
- Weak navbars
- Plain cards
- Boring sections
- Cheap-looking gradients
- Too much text without hierarchy
- Overloaded animations
- Poor mobile spacing

## Brand Positioning

The website owner sells professional websites for:

- Contractors
- Real estate businesses
- Restaurants
- Barbers
- Cleaning companies
- Appliance stores
- Local service businesses
- Small business owners

Core message:

“I build premium websites that make local businesses look professional, attract trust, and convert visitors into customers.”

## Component Rules

Every component must feel premium.

Buttons must have:

- Clear hierarchy
- Strong hover state
- Good spacing
- Mobile-friendly size
- Optional icon
- Visible CTA text

Cards must have:

- Strong title
- Short benefit-driven description
- Visual hierarchy
- Hover effect
- Consistent spacing
- Optional badge/icon

Navbar must have:

- Strong brand identity
- Clean desktop navigation
- Professional mobile menu
- Primary CTA button
- Sticky or semi-sticky behavior if useful

Forms must have:

- Clean labels
- Good spacing
- Helpful placeholders
- Strong submit button
- Trust text near the form

## Conversion Rules

Every major section should answer one of these:

- What do you do?
- Who is it for?
- Why should I trust you?
- What do I get?
- How much does it cost?
- What should I do next?

Every page must include strong CTAs such as:

- Get My Website
- Request a Free Quote
- See Website Packages
- Book a Consultation
- Start My Project

## Special Section Requirement

The website should include at least one memorable section inspired by Apple-style scroll storytelling.

Recommended concept:

“From Basic to Premium”

Show the transformation from a weak/basic business website into a premium high-converting website.

As the user scrolls:

- Basic navbar becomes premium
- Weak buttons become strong CTAs
- Flat cards become premium service cards
- Trust badges appear
- Contact CTA becomes stronger
- Final state shows a polished premium website

This section should communicate:

“I transform basic websites into premium digital presences that make businesses look serious and trustworthy.”

## Output Rules

Before changing code:

1. Briefly explain what you will improve.
2. Then edit the code.
3. After editing, summarize what changed.
4. Mention files modified.
5. Check responsive behavior.
6. Avoid breaking existing functionality.

## Quality Standard

The result should look like a premium digital agency website, not a beginner portfolio.

Think “final boss website.”

No generic templates. No weak buttons. No boring sections.
